# 4. ETL PIPELINE

Create a proper modular ETL system.

Implement:

## Extract

Read the CSV files.

Log:

* number of files
* number of records
* ingestion timestamp
* successful/failed ingestion

## Transform

Use PySpark for the main transformation process.

Perform:

* missing-value handling
* duplicate removal
* datatype conversion
* date parsing
* invalid-record detection
* joins between customers/products/orders
* calculated revenue
* calculated discount amount
* calculated net revenue

Example:

gross_revenue = quantity × unit_price

net_revenue = gross_revenue - discount_amount

## Load

Load cleaned/transformed data into SQLite.

Create sensible tables such as:

* customers
* products
* orders
* sales_fact
* daily_sales_summary
* product_sales_summary

Use proper primary keys and relationships where appropriate.
